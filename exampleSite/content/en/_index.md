# _Hugo-foxx creates fast and eco-friendly websites, yet beautiful and inclusive by design._

At first,
I wanted something minimalist like [Bear Blog](https://bearblog.dev/)
 with a clean navigation sidebar like the portfolio site of [Neil Krug](https://web.archive.org/web/20260710020918/https://www.neilkrug.com/).
The core code is derived from [hugo-brewm](https://github.com/foxihd/hugo-brewm) theme,
 I somehow managed to trim half of it.
The challenge lies in keeping the codebase from becoming bloated,
 like the bionRead feature added I added lately.
I realize this might stray slightly from the Bear Blog concept,
 but I hope the benefits outweigh the drawbacks.

Most of the code made by human I suppose,
 I don’t think any AI was involved,
 unless perhaps for some transliteration, as I’m not very fluent in English.
Having said that, I’m simply too lazy to write any documentation.
However, this exampleSite is deployed on Github Pages within it's theme repository.
You can explore how the structure, configuration, and frontmatter affect the output.
